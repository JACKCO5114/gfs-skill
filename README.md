gfs-reading
一个读书裁决工具。

手里有一本别人推荐的、收藏了没读的、买了堆着的书，纠结"现在到底该不该读"——把书名和你这周正在做的事告诉它，它给你一个干脆的结论：读 / 不读 / 只读哪部分。

它怎么判
只用一条标准：这本书接不接得上你此刻手头正在做的具体事。

接得上 → 读
接不上 → 不读（无论它多有名）
部分接得上 → 只读那部分
不打分、不排名、不搞"值得读指数"。它只回答一个是非题：这本书能不能服务你这周那件事。

为什么标准这么窄
故意的。"什么书都值得读读看"是句正确的废话，给不出任何决定。把标准收窄到"当下任务匹配度"，才能给出干脆的裁决，也才能帮你从一堆别人塞来的书单里解脱出来。

怎么用
 把地址复制到任何agent  ，↓↓
  
  安装一下 https://github.com/JACKCO5114/gfs-skill

直接说：/gfs-reading
或者：「这本《XXX》我现在该读吗，我这周在做……」
它会问你两件事（哪本书、这周在做什么），然后出裁决。

一句提醒
这是个判官，替你做"现在读不读"的决定。它干脆好用，但长期目标是你自己养出"一眼看出这书此刻有没有用"的直觉。把它当拐杖用一阵，养出感觉了就慢慢扔掉。


# 肉身翻译 / Flesh Translator

一个把"懂了却不疼"的话，翻译成"让身体一缩"的画面的工具（Claude Skill）。

你读到一个道理，"知道了"，然后没动——因为它停在脑子里，没落到身体上。肉身翻译制造那一下生理反应：心疼、肉痛、后背一凉。你身体一缩，才算真懂，才会真做。

## 它和"打比方"不一样

普通比方追求"像"。肉身翻译追求"疼"。

做法上的区别：肉身翻译先抓出原句里那个**判断标准**，再原样搬进一个有痛感的新场景。动作可以换皮，标准一个字都不能变。

举例 —— 原句：「删掉的东西里，事后要恢复的不到 10%，说明你删得还不够。」

刀口是："切得太干净反而说明没切够，切对了一定带点痛。"把这把刀砍在不同的肉上：

- 剪花园：剪完地上没有一根让你心疼的枝 → 你拿的是梳子不是剪刀
- 做手术：切完边缘干干净净不是好消息 → 切对了一定带着一点好肉
- 收房间：扔完站在半空衣柜前要有一阵肉痛 → 没肉痛的只是在表演整理

三个画面不同，判断标准一模一样。这就是它成立的全部秘密。

## 每次给三种译法

- **A 直接替换** —— 最锋利，一句话点破
- **B 场景还原** —— 最有画面，铺一个有转折的场景
- **C 对比翻译** —— 最能骂醒，两种人并排

你挑最戳的那一发。

## 什么句子翻得动

有"该怎么做 / 怎么算做对"判断的句子翻得动，尤其是反直觉的（"越 X 反而越 Y"）。纯事实、纯定义（"光速每秒三十万公里"）翻不动——没有刀口，咬不住。
